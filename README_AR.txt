Emberfall Arena — بداية اللعب الجماعي عبر الإنترنت

الملفات:
- Emberfall_Arena_Online.html: اللعبة الأصلية مع نافذة غرفة أونلاين.
- server.js: خادم WebSocket لإنشاء الغرف والانضمام إليها وتمرير الرسائل.
- package.json: إعداد تشغيل الخادم.

تنبيه مهم:
هذه نسخة تأسيسية: نظام الغرف والاتصال موجود، لكن مزامنة المعركة كاملة (الجنود والطاقة والأبراج والفوز والخسارة) لم تُربط بعد بمحرك اللعبة. لذلك لا تعتبرها نسخة مكتملة للعب ضد خصم حقيقي حتى الآن.

تشغيل الخادم على جهاز كمبيوتر:
1) ثبّت Node.js.
2) افتح الطرفية داخل المجلد.
3) نفّذ: npm install
4) نفّذ: npm start
5) انشر الخادم على استضافة تدعم WebSocket للحصول على عنوان wss:// يمكن لصديقك الوصول إليه.

لا تستخدم localhost إذا كان صديقك على جهاز مختلف؛ localhost يشير إلى جهاز كل لاعب نفسه. لا تضع بيانات سرية داخل اللعبة.
